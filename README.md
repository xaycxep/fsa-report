# async-fsa-report
Асинхронный сборщик данных о поверке СИ из API ФГИС «Аршин» с выгрузкой в XML по заданной схеме.

## Стек

- Python 3.8+
- httpx (async)
- pandas (чтение Excel)
- PyYAML (конфигурация)
- tqdm (прогресс-бар)
- pytest (тесты)

## Использование
bash
python main.py

Откроется диалог выбора Excel-файла.

Скрипт прочитает номера сертификатов из указанных колонок.

Параллельно загрузит данные из API ФГИС.

Соберёт итоговый XML.

Логи — в logs/vri.log, результат — в reporting_verification_MI.xml.

## Что внутри
Async-загрузка с Semaphore для ограничения параллелизма.

RateLimiter — не чаще N запросов в секунду, чтобы не получить 429.

Retry с экспоненциальным backoff на 429 и 5xx.

Два формата ответа API нормализуются в один (_normalize_item).

Логирование в файл с ротацией.

19 тестов на pytest, без реальной сети (httpx.MockTransport).
